# Word2PDF Bookmark Generator

**High-quality PDF export, automatic bookmark generation, and PDF merging tool on macOS based on Microsoft Word and PyMuPDF**


------------------------------------------------------------------------

## Description

When using Microsoft Word on macOS to save your thesis as PDF:

- If you choose "Best for electronic distribution", bookmarks are automatically generated, but image quality is compressed.
- If you choose "Best for printing", image quality is preserved, but bookmarks are not generated.

This project solves the problem by calling Microsoft Word from the terminal to export two DOCX files as PDFs with the "Best for printing" option, then merging the exported PDFs, and finally using PyMuPDF to generate bookmarks for the merged PDF.

**Notes:**

- This tool handles exactly two DOCX files—converting them to PDF, merging, and generating bookmarks. It is designed for this specific scenario.
- Although the script copies the original files into the `merge/` folder before processing, please back up your original files as a precaution.

## File structure:

```text
project/
├── merge_paper.command
├── word1-preface.docx
└── word2-content.docx
```

## Usage

- Before using, install PyMuPDF:
```shell
python3 -m pip install pymupdf
```

- Download `merge_paper.command` and place it in the project/ directory.

- Grant execute permission in the terminal:
```shell
chmod +x merge_paper.command
```

- Edit the beginning of merge_paper.command to set your file names:
```text
WORD1_NAME="word1-preface.docx"
WORD2_NAME="word2-content.docx"
```

- Double-click `merge_paper.command` to run it.

- If Microsoft Word asks for permission, allow it.

## Final Output
Everything inside the `merge/` folder is generated by the script. The final PDF with bookmarks is `Dissertation-Final.pdf`.


```text
project/
├── merge_paper.command
├── word1-preface.docx
├── word2-content.docx
│
└── merge/
    ├── word1-preface.docx
    ├── word2-content.docx
    ├── word1-preface.pdf
    ├── word2-content.pdf
    ├── create_bookmarks.py
    ├── Dissertation-Final.pdf
    └── Dissertation-Final.pdf.bookmark_log.txt
```
